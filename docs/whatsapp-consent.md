# WhatsApp consent — copy/paste text

Sign-up happens entirely in WhatsApp, so this is where consent actually gets
recorded. A terms page nobody accepted is weak evidence; a timestamped "agree"
from a named phone number is strong evidence.

Three things to set up, then one line per game post forever after.

---

## 1. Group description

Settings → Group info → tap the description. Keep it short; WhatsApp truncates.

```
Bangalore Volleyball Club — a noticeboard for weekly pick-up games across the city.
Every game is arranged independently by the member hosting it.
18+. You play at your own risk. Volunteers, not coaches. Court cost split, no profit.
Terms: https://volleyblr.in/terms.html
```

## 3. Footer on every game post

Repetition per game beats one-time consent — it's much harder for someone to say
they never saw it. Paste this at the bottom of each game announcement, with your
own name filled in:

```
Hosted by <name>, who arranges this session independently. By joining this list
you confirm you're 18+, have read https://volleyblr.in/terms.html, and play at
your own risk.
```

**Name the host, every time.** The terms say a session belongs to the member
identified as its host, and this line is what identifies them. A post with no
named host is a post that looks like "the club" ran the game.

## Rules for hosts

- **Put your name on the session you host**, in the post and in the footer. The
  whole structure rests on each game having an identifiable host.
- **Don't post a game in a way that implies "the club" is running it.** "BVC game
  on Sunday" is the wrong shape; "Sunday session, hosted by me" is the right one.
- **Never clear the group history.** It's your evidence. If you ever need to
  prove someone accepted the terms, it lives in this chat. Members can ask to be
  removed from the group and off any list you keep, but nobody can delete
  messages already sent — don't promise otherwise.
- **Don't delete game posts** — the player list for a given date is the record of
  who was there.
- New member who hasn't replied "agree" → don't add them to a list yet. Nudge them.
- If someone says they're under 18, they can't play. No exceptions, and it's not
  personal — a minor can't give valid consent, so a waiver from them is worthless.
